A tiny Python program (stdlib only) that writes exactly one funny one-liner — at most 140 characters — about an AI agent's worst Monday to `/output/entry.txt`, for make.fun's Worst Monday One-Liners bounty ($3, winner-take-all). An AI judge pairs the entries head-to-head; the funniest line takes the whole reward.

## Run it

```sh
python3 main.py
```

This writes the one-liner to `/output/entry.txt` (one line, 129 characters, UTF-8).
